# BRIGHT-Flash 中文研究汇报

一套可离线运行、可部署到 GitHub Pages 的动态学术汇报网页。包括 18,756 例队列图表、跨倍率蒸馏交互图、P1–P4 实验矩阵及真实结果占位。

**直接预览：** 双击 `index.html`；或运行 `python3 scripts/serve.py`，打开 `http://127.0.0.1:4173/`。无需安装前端依赖。

**交给 Codex：** 阅读 [完整中文开发提示词](docs/CODEX_PROMPT.md)，按 [执行说明书](docs/EXECUTION_GUIDE.md) 运行与部署。研究方法边界见 [科学核对说明](docs/SCIENTIFIC_NOTES.md)，检查记录见 [验证记录](docs/VALIDATION.md)。

目录：`assets/` 可引用 SVG/PNG，`data/` 计数与结果登记模板，`scripts/` 检查/预览/打包，`.github/workflows/pages.yml` 部署配置。

本项目只制作网页与研究呈现，没有运行训练或产生任何性能数值；两条主对齐关系来自用户补充，剩余交叉配对与具体算子保留待核对标记。未创建 GitHub 仓库，未推送，未上线。
