## 信息来源

研究结构与病例计数来自本次用户需求。参考会话为“评估交叉蒸馏可行性”，会话 ID `6ad6e10e-3ae0-83e8-ab75-acd3f191240e`。读取原会话后，先前助手的回答仅含内容引用标记，没有原公式、代码或附件，因此不能据此宣称已核实损失实现。

本轮用户补充确认了以下关键点：教师 16 个 tile 的 16 个 CLS token 聚合得到 1 个 CLS；学生的 1 个 CLS 经投影逼近它。学生内部的 16 个 Patch token 与教师 16 个 tile 的 Patch 目标逐一对应，学生通过投影逼近教师输出，体现同视野缩小的设计。网页已据此更新，不再把学生 16 Patch 视为未知网格。

## 必须保留的研究边界

- 计数来自用户，不是独立病例审计。五队列是否重叠、跨队列是否同一患者、配对可用率及最终纳入数需要研究团队确认。页面不把总计称为“已实际训练样本量”。
- 79.27%、1.02%、10.69%、6.05%、2.96% 是显示值，和为 99.99%。计算与环形绘图使用未舍入值。
- 4×4 空间关系基于相同图块像素边长和正确的物理尺度配准；概念图尺寸不代表真实模型输入像素或 token 维度。
- 图中粒子代表教师知识指导，不代表教师梯度，也不是训练进度。
- SNGP-1007 与 SNGP-ex 必须分别根据对应特征训练；不同分支允许选出不同位置，但数量预算及规则一致。同一分支切换 20× 编码器时应复用相同坐标。
- SNGP 排序使用哪个量、升序还是降序、如何处理并列与候选不足，都需要预先确定。网页不替研究团队指定。
- 冻结策略及任务头训练方式在下游 20× 阶段仍需预注册；本轮蒸馏教师被冻结，并不自动决定所有下游编码器的训练方式。
- 患者级划分应覆盖蒸馏数据：若独立测试患者参与了无监督蒸馏，也不能再称其为严格未见患者测试。传导式设置需单独声明，不能与严格独立测试混报。
- 1007/ex 的对照是表征与对应 SNGP 的联合分支效应。若要独立归因数据与教师，还需额外蒸馏消融。若要独立归因选区策略，也需固定表征后另设选区消融。
- 任务未指定，AUROC/AUPRC/ECE/Brier/AURC 是候选指标；具体任务下的定义、CI、样本单位与多重比较方案需预注册。
- 全部结果均待测；没有生成任何模拟 AUROC、虚构效果或病理热图。

## 配对映射与公式复核清单

1. 索引：16 tile 的行列顺序与学生 16 Patch 顺序一致吗？裁块是否含 overlap/padding/背景过滤？
2. 全局目标：16 CLS 采用哪种聚合，有无归一化或训练参数，最终维度是多少？
3. 局部目标：每个教师 tile 内的多个 Patch token 如何变成学生对应目标？是否需要池化、重排或其他映射？
4. 投影：学生两头输入/输出维度、共享关系、非线性与归一化具体是什么？
5. 交叉路：另外两路精确作用于哪些特征、是否有额外聚合、是否与页面候选配对一致？
6. 损失：四路权重、批次与空间位置的 reduction、stop-gradient 位置以及 cosine 的 epsilon 是什么？
