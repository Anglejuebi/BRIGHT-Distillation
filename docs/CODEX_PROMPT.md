## 3. 蒸馏方法页：保持原范式

### 已确认的输入、token 与更新关系

1. 本轮 **20× H-optimus-1 为冻结教师**，禁止反向更新教师；**5× BRIGHT-Flash-ex 为可训练学生**，学生及其投影参与更新。
2. **16 个 20× tile 与 1 个 5× tile 覆盖同一物理视野**。在相同像素边长、采样尺度正确匹配的条件下，4 倍线性倍率比产生 4×4 区域对应。实际配对需依据 MPP、坐标、层级与覆盖边界校验。
3. 教师 16 个 tile 输出 16 个 CLS token，聚合为 **1 个教师 CLS 目标**。学生的 **1 个 CLS token** 经学生 CLS 投影逼近它。用户未指定聚合具体算子，不能默认平均池化。
4. 按用户说明，学生内部将一个 5× tile 划为 **16 个 Patch token**；它们分别与教师 **16 个 20× tile 的 Patch 目标**空间对应。学生 Patch token 经学生 Patch 投影逼近相应目标，体现“同视野、尺寸缩小”。
5. 教师每个 tile 内可能有多个 Patch token；用户未提供如何形成 tile 级对应目标，不能自动简化为“每个教师 tile 天然只有 1 个 Patch token”。
6. **CLS/Patch 双学生投影与四路 cosine alignment** 是用户指定的原范式。已明确主关系 CLS→CLS 和 Patch→Patch；另外两路交叉配对尚未完整提供。

### 四路图示与核对要求

- 可以用 `CLS→CLS`、`Patch→Patch` 加上候选 `CLS→Patch*`、`Patch→CLS*` 展示四路结构，但必须以颜色、线型与文字区分“主对齐已确认”和“交叉配对待核对”。
- 不得把两个候选交叉关系包装成已核实的原公式。拿到原代码后再更新 `data/research-data.js` 中的 `method.routes`、路径、标签、符号、说明和状态。
- 可用符号表达 `L = Σ λ_ab [1 − cos(P_a(S_a), sg(A_b(T_b)))]`，但注明是结构示意：A 是待核对的目标构造，权重、投影维度、归一化及采样策略未定，不表示训练实现已复现。
- `sg` 仅用于表示教师目标停止梯度。这里的双投影属于学生，不能写成两个教师投影头。

### 交互与动画

- 教师 4×4 图块与学生 4×4 内部区域同步高亮；编号 01–16，点击、Tab、方向键均可操作，提供文本说明。
- 教师冻结、学生更新、全局 CLS 聚合和局部 Patch 空间对应都有明确标签。
- 对齐路径支持单路高亮、重复点击恢复全部。粒子沿教师目标到学生投影方向流动；标明粒子表示知识指导，不是梯度流。
- 提供完整流程/空间映射/四路对齐聚焦状态，以及方法边界弹窗。
- 动画服务讲解，默认低频、轻量，无闪烁、无自动轮播、无自动音效。

## 4. 后续实验：必须先评测，再训练，再组合

### 阶段 A：独立评测 5× 模型

分别评测 BRIGHT-Flash-1007 与 BRIGHT-Flash-ex。固定患者划分、任务定义、标签、评价头及训练/调参预算；目的为评估低倍表征是否改变，不提前声称 ex 更好。任务头是线性探针、MIL 或其他方案，应由研究者预先确定。

### 阶段 B：分别训练 SNGP

- 1007 特征 → 训练 SNGP-1007。
- ex 特征 → 训练 SNGP-ex。
- SNGP 的特征变换、校准与超参数仅用训练/验证数据拟合，不能接触测试标签。
- 目的为检验对应表征下的预测、不确定性与选区行为。候选指标包括 ECE、Brier、AURC；若有病灶/ROI 参考，可预先定义选区命中率或覆盖率。无 ROI 标注不得宣称选区准确率。

### 阶段 C：统一 Top-N 选区后连接两个 20× 编码器

| 组别 | 5× 模型 | 对应 SNGP | 选区 | 下游 20× 编码器 |
| --- | --- | --- | --- | --- |
| P1 | BRIGHT-Flash-1007 | SNGP-1007 | 统一 Top-N | BRIGHT-S |
| P2 | BRIGHT-Flash-1007 | SNGP-1007 | 统一 Top-N | H-optimus-1 |
| P3 | BRIGHT-Flash-ex | SNGP-ex | 统一 Top-N | BRIGHT-S |
| P4 | BRIGHT-Flash-ex | SNGP-ex | 统一 Top-N | H-optimus-1 |

必须准确区分：本轮蒸馏教师仅为 H-optimus-1；BRIGHT-S 与 H-optimus-1 在 P1–P4 中均是最终下游编码器。

- P1/P2 复用完全相同的选区坐标；P3/P4 同理。跨 SNGP 分支可选不同坐标，这正是分支效应的一部分。
- Top-N 数量、候选区域生成、空间配准、排序方向、并列打破规则、候选不足 N 时的处理及阈值要统一并记录。网页 Top-N 输入只是演示参数，不运行模型或重算性能，不预设一个数值为最终实验值。
- 二因素矩阵可点击，显示完整链路、用途、比较对象；不能只画四张无关联卡片。
- 固定 20× 编码器：P3 vs P1、P4 vs P2，检验“5× 表征 + 对应 SNGP”的联合效应，不能称为纯 SNGP 效应。
- 固定选区分支：P2 vs P1、P4 vs P3，检验高倍编码器效应。
- 若预注册，可分析 `(P4−P3)−(P2−P1)` 的交互，使用同尺度指标与患者级配对统计；不预设结果方向。
- 1007 与 ex 同时涉及数据扩充及教师替换。若要拆分二者贡献，另加“原/扩充数据 × BRIGHT-S/H-optimus-1 蒸馏教师”消融。不能把 P1–P4 当作该消融。
