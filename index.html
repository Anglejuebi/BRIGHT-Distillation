方法边界与符号

已确认的结构来自本次需求：20× H-optimus-1 冻结教师、5× BRIGHT-Flash-ex 学生、16∶1 同视野对应、CLS/Patch 双学生投影和四路 cosine alignment。

本轮补充已确认：教师 16 个 tile 输出的 16 个 CLS token 聚合为一个 CLS 目标；学生 1 个 CLS 经投影逼近它。学生内部将一个 5× tile 划分为 16 个 Patch token，按空间位置逐一对应教师 16 个 20× tile 的 Patch 目标。

待原实现核对：CLS 聚合具体算子、教师每个 tile 内 Patch token 如何形成对应目标、投影维度、损失权重，以及另外两路交叉配对。带 * 的 CLS→Patch、Patch→CLS 是候选示意，不能视为已核实的原损失。

不默认对 16 个 CLS 取平均。A 表示待确认的聚合或映射；sg 表示教师目标停止梯度。真实实现需在维度和空间语义相容后计算 cosine loss。

倍率比推导的 4×4 覆盖要求两个倍率图块具有相同像素边长且物理分辨率匹配；实际裁块需核对扫描层级、MPP、坐标与边界覆盖。
